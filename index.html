What I’m building now

Stats Perform

AI Intern, remote, since June 2025

I’m building an internal tool that writes publication-ready sports articles for The Analyst. It pulls grounded context from Opta’s data, drafts with a fast LLM, and refuses to render anything that doesn’t pass validation.

The target is a World Cup 2026 commercial use case, so reliability matters as much as prose: retries for flaky model calls, graceful failures, and safety checks that block forbidden markup before a page ever ships.

how one article gets made
  1. RetrieveInternal Opta RAG API and the OptaAI Chat endpoint supply the match facts.
  2. GenerateGroq-hosted LLM inference drafts the article from that grounded context.
  3. Validatepydantic-AI orchestrates the flow and checks every required section exists.
  4. RenderContent maps into a fixed HTML template with live preview, raw view, and download.

Python, pydantic-AI, Groq, RAG, HTML
